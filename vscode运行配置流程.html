在 VSCode 里点按钮直接编译运行 C++
只需要装一次插件，以后每次点 ▶ 就行
装 Code Runner 插件（30秒搞定，只做一次）
① 点 VSCode 最左边栏那个 四个方块 图标（扩展），或按 Ctrl+Shift+X
② 顶部搜索框输入：Code Runner
③ 找到作者是 Jun Han 的那个，点蓝色 Install 按钮
④ 装完后，打开任意 .cpp 文件，右上角会出现一个 ▶ 三角形按钮
以后每次写代码的日常流程
① 改 1.cpp 里的代码
② 点右上角 ▶（或按 Ctrl+Alt+N）
③ 底部终端自动跑：g++ 编译 → 生成 exe → 运行 → 输出结果
④ 看结果不满意？改代码，再点一次 ▶
⑤ 代码满意了？去左边源代码管理面板，提交 + push 到 GitHub
关于"没有编译器要不要重装"
你现在的 g++ 是 Amesim 自带的，不用重装，写课上的代码完全够。
但它是 2007 年的老版本（g++ 4.2.1），以后如果用到 auto、vector、范围for、C++11新特性 报错，再装新版编译器（到时候叫我，我带你装 MinGW-w64 或 Visual Studio Build Tools）。
