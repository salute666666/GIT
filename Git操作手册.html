一、认识 VSCode 的 Git 面板
点 VSCode 最左边栏那个分支圆圈图标（或按 Ctrl+Shift+G），打开"源代码管理"面板。它由上到下分三块：
区域作用
消息输入框（顶部）写"这次改了什么"的备注，一句话
✓ 提交按钮点它 = git commit（拍快照）
"更改"列表列出你改过/新建的文件。文件右边：+号=暂存，-号=取消暂存，↶=丢弃改动
二、日常循环（每天重复这5步，记住就够用）
场景：你刚改完 1.cpp，想保存这次进度并上传 GitHub。

第1步：按 Ctrl+Shift+G 打开源代码管理面板，你会看到 1.cpp 出现在"更改"里（字母 M = Modified 改过了）。

第2步：把鼠标移到 1.cpp 那一行，点右边出现的 + 号。
→ 文件会从"更改"跳到"暂存的更改"分组里。这步 = git add（选好要打包的文件）。
→ 想全部暂存：点"更改"三个字右边的 + 号，一次性全选。

第3步：顶部消息框里写一句备注，例如：给main函数加了数组遍历
→ 写人话，以后回看能看懂改了啥。

第4步：点蓝色 ✓ 提交 按钮（或按 Ctrl+Enter）。
→ 这步 = git commit（拍快照存档）。左下角会闪过一个数字，表示提交成功。

第5步：点面板右上角 "..." → 选 "推送"（Push）。
→ 这步 = git push（把快照上传 GitHub）。
→ 第一次可能弹浏览器让你登录 GitHub，登录一次以后不再问。

🎉 完成！ 打开 github.com/salute666666/GIT 就能看到新代码。
三、查看历史版本（我之前到底改了啥）
方法1（图形界面）：源代码管理面板右上角 "..." → 视图 → 历史记录。会列出所有提交，点任意一条能看到那个版本改了哪些行。

方法2（命令面板）：按 Ctrl+Shift+P → 输入 Git: View History。

方法3（终端）：底部终端输入 git log --oneline，会列出一串快照号和备注。
四、救急操作（改坏了怎么办）
情况A：代码改乱了，还没提交，想丢弃这次改动
源代码管理面板 → 鼠标移到那个文件上 → 点右边的 ↶ 回退箭头（放弃更改/Discard Changes） → 确认。
代码立刻恢复到上次提交时的样子。注意：未提交的改动会永久丢失。
情况B：已经提交了，但发现这次提交是错的，想撤回这次提交
面板"..." → 提交 → 撤销提交（Undo Commit）。代码改动会退回到"暂存"状态，让你重新整理再提交。
情况C：想把整个项目退回到某个历史版本
先在历史记录里找到目标版本号（如 513ebf7），终端执行：
git reset --hard 513ebf7
警告：这会丢弃该版本之后的所有改动，慎用。
五、分支（平行试验新功能，不影响主代码）
理解：main 是主线稳定版。分支 = 从主线切出去一条平行空间，你在里面随便折腾，搞砸了删掉就行，main 永远干净。

在 VSCode 里操作：
① 点 VSCode 左下角那个蓝色圆圈（显示 main 的地方）。
② 弹出菜单选 "创建分支的分支"。
③ 输入分支名，例如 test-pointer，回车。
④ 之后你所有提交都在这个分支上，main 不变。
⑤ 想切回主线：再点左下角，选 main。
⑥ 试验成功想合并回主线：先切到 main → 面板"..." → 分支 → 合并分支 → 选 test-pointer。
六、拉取远程最新代码（pull）
如果你在另一台电脑或网页上改了 GitHub 上的代码，本地要下载下来：
面板"..." → 拉取（Pull）。

如果推送时报错：提示"本地和远程有分叉"，先做一次"拉取"，等它自动合并，再点"推送"。
你现在的状态就是这种：本地和远程差了各1个提交，下次先拉再推就行。
七、克隆别人的仓库到本地（clone）
想把 GitHub 上某个项目下载到自己电脑：
① 按 Ctrl+Shift+P → 输入 Git: Clone
② 粘贴仓库地址（如 https://github.com/salute666666/GIT.git）
③ 选一个本地文件夹存放。
